🔢 Important Physical Constants (MEMORIZE!)

c (Speed of light): 3 × 10⁸ m/s
h (Planck's constant): 6.626 × 10⁻³⁴ J·s
G (Gravitational const): 6.67 × 10⁻¹¹ N·m²/kg²
k_B (Boltzmann): 1.38 × 10⁻²³ J/K
R (Gas constant): 8.314 J/(mol·K)
N_A (Avogadro): 6.022 × 10²³ /mol
k (Coulomb's const): 9 × 10⁹ N·m²/C²
e (Electron charge): 1.6 × 10⁻¹⁹ C
m_e (Electron mass): 9.11 × 10⁻³¹ kg
m_p (Proton mass): 1.67 × 10⁻²⁷ kg
μ₀ (Permeability): 4π × 10⁻⁷ H/m
ε₀ (Permittivity): 8.85 × 10⁻¹² F/m

Kinematics

  • • Motion in 1D, 2D, 3D - Displacement, velocity, acceleration
  • • v = u + at, s = ut + ½at², v² = u² + 2as
  • • Projectile motion: R = u²sin2θ/g, H = u²sin²θ/2g
  • • Circular motion: v = rω, a = v²/r = rω²
  • • Relative velocity concepts

Newton's Laws & Dynamics

  • • Newton's three laws of motion
  • • Force, momentum: p = mv, F = dp/dt
  • • Friction: μₛ (static), μₖ (kinetic), f = μN
  • • Banking of roads: tanθ = v²/rg
  • • Tension, Normal force problems

Work, Energy & Power

  • • Work: W = F·s = Fs cosθ
  • • Kinetic energy: KE = ½mv²
  • • Potential energy: PE = mgh (gravitational), PE = ½kx² (spring)
  • • Work-Energy theorem: W = ΔKE
  • • Conservation: KE + PE = constant
  • • Power: P = W/t = F·v

Rotational Motion

  • • Angular: θ, ω, α (displacement, velocity, acceleration)
  • • Moment of inertia: I = Σmr²
  • • Torque: τ = r × F = Iα
  • • Angular momentum: L = Iω (conserved)
  • • Rotational KE: ½Iω²
  • • Rolling: v = Rω

Gravitation

  • • Newton's law: F = Gm₁m₂/r²
  • • Field: g = GM/r², Potential: V = -GM/r
  • • Escape velocity: v_e = √(2GM/R)
  • • Orbital velocity: v₀ = √(GM/r)
  • • Kepler's three laws, Satellite motion

Wave Motion

  • • Wave equation: y = A sin(kx - ωt)
  • • Wave speed: v = fλ = ω/k
  • • Progressive & standing waves, Superposition
  • • Beats: Beat frequency = |f₁ - f₂|
  • • Doppler effect: f' = f(v ± v₀)/(v ∓ vₛ)

Geometrical Optics

  • • Mirror formula: 1/f = 1/v + 1/u
  • • Snell's law: n₁sinθ₁ = n₂sinθ₂
  • • Critical angle: θ_c = sin⁻¹(n₂/n₁)
  • • Lens maker: 1/f = (μ-1)(1/R₁ - 1/R₂)
  • • Lens formula: 1/f = 1/v - 1/u
  • • Magnification: m = v/u = h'/h

Wave Optics

  • • Huygens' principle, Interference patterns
  • • Young's double slit: β = λD/d
  • • Thin film interference, Newton's rings
  • • Diffraction grating: nλ = d sinθ
  • • Polarization - Malus' law: I = I₀cos²θ
  • • Brewster's angle: tanθ_B = n₂/n₁

Electrostatics

  • • Coulomb's law: F = kq₁q₂/r² where k = 9×10⁹
  • • Electric field: E = F/q = kQ/r²
  • • Gauss's law: Φ_E = Q/ε₀
  • • Potential: V = kQ/r, E = -dV/dr
  • • Capacitance: C = Q/V = ε₀A/d
  • • Energy: U = ½CV² = ½QV
  • • Series: 1/C = 1/C₁ + 1/C₂, Parallel: C = C₁ + C₂

Current Electricity

  • • Ohm's law: V = IR
  • • Resistance: R = ρL/A
  • • Power: P = VI = I²R = V²/R
  • • Kirchhoff's laws (KCL & KVL)
  • • Wheatstone bridge: balanced when P/Q = R/S
  • • RC circuits: τ = RC

Magnetism

  • • Force: F = qvB sinθ
  • • Lorentz force: F = q(E + v × B)
  • • Biot-Savart & Ampere's law
  • • Straight wire: B = μ₀I/2πr
  • • Solenoid: B = μ₀nI
  • • Force on wire: F = BIL sinθ
  • • Torque: τ = NIAB sinθ

Electromagnetic Induction

  • • Faraday's law: ε = -dΦ_B/dt
  • • Motional emf: ε = Blv
  • • Self-inductance: ε = -L(dI/dt)
  • • Energy in inductor: U = ½LI²
  • • AC: X_L = ωL, X_C = 1/ωC
  • • Impedance: Z = √(R² + (X_L - X_C)²)
  • • Transformer: V_s/V_p = N_s/N_p = I_p/I_s

Maxwell's Equations

  • • ∮E·dA = Q/ε₀ (Gauss-Electric)
  • • ∮B·dA = 0 (Gauss-Magnetic)
  • • ∮E·dl = -dΦ_B/dt (Faraday)
  • • ∮B·dl = μ₀(I + ε₀dΦ_E/dt) (Ampere-Maxwell)
  • • EM wave: c = 1/√(μ₀ε₀)

Thermal Properties

  • • Heat transfer: Q = mcΔT
  • • Latent heat: Q = mL
  • • Linear expansion: ΔL = αL₀ΔT
  • • Volume expansion: ΔV = γV₀ΔT where γ = 3α
  • • Conduction: Q/t = kA(T₁-T₂)/L
  • • Stefan-Boltzmann: P = σAT⁴

Kinetic Theory

  • • Ideal gas: PV = nRT = Nk_BT
  • • KE per molecule: 3/2 k_BT
  • • RMS speed: v_rms = √(3RT/M)
  • • Energy per mole: U = (f/2)RT

Laws of Thermodynamics

  • • First law: ΔU = Q - W
  • • Isothermal: ΔU = 0, W = nRT ln(V₂/V₁)
  • • Adiabatic: PVγ = const, TVγ-1 = const
  • • Heat capacities: C_p - C_v = R
  • • Carnot efficiency: η = 1 - T_c/T_h
  • • Entropy: ΔS = Q/T (always increases)

Atomic Structure

  • • Bohr radius: r_n = n²h²ε₀/(πme²)
  • • Energy levels: E_n = -13.6/n² eV
  • • Balmer series: 1/λ = R(1/2² - 1/n²), n > 2
  • • Rydberg constant: R = 1.097×10⁷ m⁻¹
  • • De Broglie: λ = h/p = h/mv

Photoelectric Effect

  • • Einstein's equation: KE_max = hf - φ
  • • Work function φ, threshold frequency f₀
  • • Stopping potential: eV₀ = KE_max
  • • Photon energy: E = hf = hc/λ
  • • Wave-particle duality

Nuclear Physics

  • • Mass defect: Δm = Zm_p + Nm_n - M_nucleus
  • • Binding energy: BE = Δmc²
  • • Radioactive decay: N = N₀e^(-λt)
  • • Half-life: t_1/2 = ln2/λ = 0.693/λ
  • • Activity: A = λN = A₀e^(-λt)
  • • Alpha, beta, gamma decay, Fission & Fusion

Special Relativity

  • • Time dilation: Δt = γΔt₀ where γ = 1/√(1-v²/c²)
  • • Length contraction: L = L₀/γ
  • • Mass-energy: E = mc²
  • • Relativistic energy: E² = (pc)² + (m₀c²)²

Crystal Structure

  • • Crystal lattice: SC, BCC, FCC
  • • Unit cells, coordination number
  • • Miller indices (hkl)
  • • Bragg's law: nλ = 2d sinθ

Band Theory & Semiconductors

  • • Energy bands: valence & conduction
  • • Band gap E_g: Insulator (>3 eV), Semiconductor (~1 eV)
  • • Intrinsic: n_i = √(n_e n_h) ∝ T^(3/2) e^(-E_g/2kT)
  • • Extrinsic: n-type (donor), p-type (acceptor)
  • • Hall effect: R_H = 1/ne
  • • Conductivity: σ = ne(μ_e + μ_h)

Semiconductor Devices

  • • p-n junction: depletion region, barrier potential
  • • Diode equation: I = I₀(e^(qV/kT) - 1)
  • • Zener diode, LED, photodiode, solar cell
  • • BJT: NPN, PNP transistors
  • • Current gain: α = I_C/I_E, β = I_C/I_B
  • • FET, MOSFET basics

Digital Electronics

  • • Logic gates: AND, OR, NOT, NAND, NOR, XOR, XNOR
  • • Boolean algebra, De Morgan's laws
  • • Half adder, full adder
  • • Flip-flops: SR, JK, D, T
  • • Counters, registers, ADC/DAC

Amplifiers & Oscillators

  • • Amplifier gain: A_v = V_out/V_in
  • • Feedback: positive (oscillators), negative (stability)
  • • Op-amp: inverting, non-inverting, summing
  • • Oscillators: LC, RC (Wien bridge), crystal

Vector Analysis

  • • Scalar & vector products: A·B, A×B
  • • Gradient: ∇φ, Divergence: ∇·A, Curl: ∇×A
  • • Line, surface, volume integrals
  • • Gauss's divergence theorem
  • • Stokes' theorem, Green's theorem

Differential Equations

  • • First order: separable, linear, exact
  • • Second order: homogeneous & non-homogeneous
  • • Solution methods for constant coefficients
  • • Wave equation, heat equation, Laplace equation

Fourier & Complex Analysis

  • • Fourier series expansion
  • • Fourier transform & inverse
  • • Complex numbers: z = x + iy
  • • Euler's formula: e^(iθ) = cosθ + i sinθ
  • • Cauchy-Riemann equations
